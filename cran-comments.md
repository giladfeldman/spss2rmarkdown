## Package description

spss2rmarkdown converts SPSS .sps syntax files and .sav data files into
reproducible R Markdown reports. Parses 60+ SPSS commands, translates them
to equivalent R code using the jmv package, and generates formatted R Markdown
documents. Validated against GNU PSPP with 73/73 statistical comparisons passing.
